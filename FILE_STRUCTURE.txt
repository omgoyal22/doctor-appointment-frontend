=====================================================
API ENDPOINTS (All start with http://localhost:5000/api)
=====================================================

DOCTOR ENDPOINTS
  GET    /doctors                    List all doctors
  GET    /doctors?specialty=X        Filter by specialty
  GET    /doctors/:id                Get single doctor details + slots
  GET    /doctors/:id/appointments   Get doctor's appointments

APPOINTMENT ENDPOINTS
  POST   /appointments               Create new appointment
  GET    /appointments/doctor/:id    Get doctor's appointments
  PUT    /appointments/:id           Update appointment status

HEALTH CHECK
  GET    /health                     Check backend status


=====================================================
DATABASE COLLECTIONS
=====================================================

DOCTORS
  _id, name, specialty, experience, email, phone, bio, image
  availableSlots: [{date, startTime, endTime, isBooked}]

APPOINTMENTS
  _id, doctorId, doctorName, patientName, patientEmail, patientPhone
  appointmentDate, appointmentTime, status, notes
